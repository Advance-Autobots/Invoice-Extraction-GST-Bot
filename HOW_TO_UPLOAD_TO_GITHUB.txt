==============================================================================
               HOW TO UPLOAD THIS FOLDER TO GITHUB (STEP-BY-STEP)
==============================================================================

1. Open your web browser and go to: https://github.com
2. Click "+" at top-right -> "New repository".
3. Name it: "Invoice-Extraction-GST-Bot".
4. Leave ALL checkboxes UNCHECKED (Add README, .gitignore, license).
5. Click "Create repository".
6. On the new repository page, click the link: "uploading an existing file".
7. Select ALL files and folders inside this "FOR_GITHUB_UPLOAD" folder and drag 
   them into the GitHub browser window.
8. Click "Commit changes".
==============================================================================
