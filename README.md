# Invoice-Extraction-GST-Bot
Automated Python &amp; RPA Tax Audit Bot for Chartered Accountants to automate purchase register entry. Ingests PDF/image invoices, performs statutory GST checks under CGST Act Section 16(2) &amp; Rule 46, verifies tax arithmetic, detects duplicate billing, and exports 26-column ICAI-standard Excel registers with live SUM formulas.
